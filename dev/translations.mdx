NeverTooManyBooks reaches users around the world, and community translators are the reason the app speaks so many languages. All translations are managed through **Weblate**, a free, open-source platform that lets you contribute directly in a browser-based editor without touching the source code or opening a pull request. When a language's translation reaches the required completion threshold, Weblate automatically submits the changes to the GitHub repository — meaning your work goes live without any manual intervention from the maintainer. If you prefer to work with the raw string files, pull requests containing translation files are also accepted directly on GitHub.

## How to Add or Improve a Translation

<Steps>
  <Step title="Go to the Weblate project page">
    Navigate to [hosted.weblate.org/engage/nevertoomanybooks/](https://hosted.weblate.org/engage/nevertoomanybooks/).
    You will see the full list of languages and their current completion percentages.

    <Tip>
      Weblate displays translation progress as a percentage per language — a
      quick glance shows you exactly which languages need the most attention
      before you decide where to focus.
    </Tip>
  </Step>
  <Step title="Log in or create a free Weblate account">
    Click **Register** on the Weblate site. Account creation is free and
    requires only an email address. You can also sign in with a GitHub account.
  </Step>
  <Step title="Choose your language — or request a new one">
    Select the language you want to work on from the project overview. If your
    language is not listed, **do not add it directly**; instead, file a
    [GitHub Issue](https://github.com/tfonteyn/NeverTooManyBooks/issues) to
    request it. The maintainer will set up the language component on Weblate
    so it is properly integrated into the build.
  </Step>
  <Step title="Start translating strings in the web editor">
    Weblate's editor shows the English source string alongside the translation
    field. Untranslated strings are highlighted, and you can filter by status
    (e.g. "Needs editing", "Untranslated"). Context hints and screenshots are
    provided where available to help you choose the right wording.
  </Step>
  <Step title="Weblate automatically submits your changes">
    You do not need to open a pull request. Once translations in a component
    reach the configured threshold, Weblate creates a PR against the GitHub
    repository on your behalf. The maintainer reviews and merges it, and your
    translations appear in the next release.
  </Step>
</Steps>

## Submitting Translations via Pull Request

If you prefer to work locally with Android string resource files, you can submit a pull request directly to the [GitHub repository](https://github.com/tfonteyn/NeverTooManyBooks). String resources follow standard Android `values-<locale>/strings.xml` conventions. Make sure your file is encoded as **UTF-8** and that you do not alter any English source strings in `values/strings.xml`.
